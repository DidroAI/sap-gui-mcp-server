# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone who takes part in its issues, pull requests and discussions agrees
to it.

To report unacceptable behaviour, contact the maintainers privately through
GitHub ([Security → Report a vulnerability](https://github.com/DidroAI/sap-ui-mcp/security/advisories/new)
reaches them without making the report public), or by email to the address
on the maintainers' GitHub profiles. Reports are handled in confidence.
