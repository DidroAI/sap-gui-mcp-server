Agent not connecting?

In your agent's settings for this tool, set SAP_BROWSER=extension, then start a new chat.

The "controlled by automated test software" bar comes from the program that started this Chrome, not from this extension.

    Set up in a minute

    Your agent works in SAP in this Chrome, in the systems you add.

    1. Install the helper

      In a terminal, run:

      npx -y sap-ui-automation extension helper

      Then restart Chrome.

    2. Pair Chrome with the helper
      One click. After this, only your agent on this computer can use the extension.

      Pair with a code instead

      Run npx -y sap-ui-automation extension pair in a terminal, then paste the code it prints.

    3. Add your SAP systems
    4. Ask your agent
